# Bebito Oinam | Personal Portfolio

A single page personal portfolio built with plain HTML, CSS and JavaScript.

## About
I'm a 3rd year BSc Forensic Science student who loves anime, art and music.
This page mixes all of that into a pastel brutalist "case file" theme.

## Features
- Case file style profile section
- Interactive vinyl record that plays a tiny 8-bit tune
- Doodle pad you can draw on
- Draggable evidence board

## How to view
Download the repo and open index.html in any browser.

## Tech used
- HTML5 and CSS3 (grid, animations)
- Vanilla JavaScript (Canvas API, Web Audio API)
- Google Fonts
